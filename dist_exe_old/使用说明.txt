MorningBoard 每日播报 · Windows 免安装版
=======================================

【怎么用】
1. 双击 MorningBoard.exe —— 立即看今天的晨报（窗口自动弹出）
2. （可选）想每天 20:00 自动生成并弹窗：
   - 最简单：创建计划任务，每天 20:00 运行 MorningBoardGen.exe
   - 或用 Windows 任务计划程序导入示例 XML（见下文）
3. 两台 exe 都放在同一个文件夹里即可

【数据存哪】
程序首次运行会自动在 %APPDATA%\MorningBoard 创建配置与缓存：
  - config.json      （自选基金、AI 设置，可手动编辑）
  - cache\           （今日数据、历史归档、日志）
删除 %APPDATA%\MorningBoard 目录即可完全重置。

【AI 功能（可选）】
不配置也能用：每日一课 / 思辨训练 / 表达能力 会自动降级到
静态知识库 + 网络热点议题，内容不会空缺。
想启用 AI 增强：把 DeepSeek API Key 设为用户环境变量
  DEEPSEEK_API_KEY = sk-xxxx（https://api.deepseek.com 申请）
设置后重启程序生效。思辨训练默认"网络热点 + AI 加工成题"，
可在 config.json 的 ai.thinking_source 改回 "ai"（纯 AI 命题）。

【注意】
- 单文件 exe 首次启动约 2~3 秒（需要解压），属正常现象
- 个别杀毒软件会误报单文件 exe，添加信任即可
- 需联网使用（新闻 / 行情 / 热点抓取），纯离线也能开窗但内容为旧缓存

【版本说明】
- MorningBoard.exe    ：查看窗口（双击即用）
- MorningBoardGen.exe ：每晚生成入口（供计划任务调用，生成后自动弹出查看窗口）
