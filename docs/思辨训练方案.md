# 思辨训练方案（软件内落地版）

> 目标：把「读正反方观点」变成**能迁移的思维能力**——认出题型、套上框架、给出条件化结论、把论据存下来复用。
> 建立于 2026-09-14（对应原来只有 33 道题、12 个工具、12 个谬误，界面只能"看"的问题）。

## 一、先承认原来的三个毛病

| 毛病 | 表现 | 现在的解法 |
|---|---|---|
| 把题目当答案背 | 材料里 6 条正反观点读完就过，没有加工 | **二次加工三步**：正反各压成一句核心论点 → 找出「对撞点」 |
| 没有题型框架 | 每道题都从零开始组织语言 | **四类延伸题**各有固定答题动作，认出来就能套 |
| 没有限时、没有复盘 | 看完就算练过，无法迁移 | **15 分钟限时流程** + 复盘四步 + 论据库 |

## 二、四类延伸题与固定答题动作

| 类型 | 特征问法 | 答题动作 | 模板 |
|---|---|---|---|
| **权衡界定类** | 「平衡点在哪」「边界该不该重划」 | 先立原则 → 再划边界 → 最后给条件 | 原则(保护 X) → 边界(线划在 Y 侧) → 例外条件(当 Z 成立可越线) |
| **归因判断类** | 「是理性还是被裹挟」「政府该干预吗」 | 概念辨析 → 承认两者不互斥（微观合理 + 宏观失灵）→ 给判断标准 | 概念区分 → 并存 → 判断标准 → 干预对象是结构不是行为 |
| **对策类** | 「如何防止」「怎么重建」 | 分主体（政府/机构/个人）× 分环节（事前/事中/事后）→ 抽 2 条最关键并说成本 | 3×3 矩阵 → 优先级 |
| **影响类** | 「会不会加剧」「长期看怎样」 | 分受益方/受损方 × 分短期/长期 → 给净效应与前提 | 2×2 → 净效应 + 成立前提 |

界面顶部有「🧭 类型识别小测」：每天一道短题，四个按钮选类型，答对答错都记进统计（目标：2 秒认出类型）。

## 三、条件化答法：把「对错之争」变成「变量之争」

强制句式：**如果前提是……那么……；如果前提是……那么……。决定结论的关键变量是……**

两个真实例子（AI 生成，已实测）：

- *AI 客服的情绪劳动该不该算法化*：如果 AI 只做第一响应且必须保留一键转人工，那么共情算法是减压阀；如果企业用它替代赔付，**关键变量是解决率考核**，则变成拖延工具。
- *外卖超时罚款*：如果消费者可自选时效并支付溢价，那么超时成本应由其自担；**关键变量是时效选择权与溢价是否真实存在**。

自检清单（每道题答完都过一遍）：① 结论里有「在……条件下」吗？② 点出了 1–2 个关键变量吗？③ 说明了变量朝哪个方向变会翻转结论吗？

## 四、15 分钟限时流程（少而深，一周 2–3 道）

| 时间 | 动作 | 交付物 |
|---|---|---|
| 0–3 分钟 | **压缩材料**：正反各压成一句核心论点 + 找对撞点 | 三件武器：正方核心 / 反方核心 / 对撞点 |
| 3–5 分钟 | **识别类型**：这是四类中的哪一类？ | 类型 + 对应答题动作 |
| 5–12 分钟 | **套框架答题**，每题 2–3 分钟 | 条件化结论 + 变量清单 |
| 12–15 分钟 | **检查**：只盯两个差距 | 差距一：是否按类型套框架；差距二：是否还在说对错 |

## 六、论据库与复盘四步

**论据库**（界面「📚 论据库」）：按议题分类存论据（教育/医疗/住房/科技伦理…），每条记「事实 + 它能支持什么 + 适用条件」。攒够一类 5 条，这类题就不用从零起步。

**复盘四步**（界面「📅 训练统计与复盘」→ 填写复盘）：

1. **自我反驳**：写完先不看参考，自己找三个能打自己结论的反例
2. **对照参考**：只看「我没想到的论据」和「我说错的地方」
3. **抄进论据库**：把新论据按分类存进去（保存复盘时自动入库）
4. **只记两个差距**：是否按类型套框架？结论是否已条件化？—— 会显示在卡片上盯着你

## 七、三连变式（进阶）

同一道题练三遍：**换立场**（写对方最强版本，不许稻草人）→ **换角色**（家长/政府/医院/学生/企业主，约束条件不同）→ **换前提**（把关键条件改成相反条件，看结论怎么翻转）。

界面「🛠 三连变式」有两个入口：**开始变式训练**（给引导语，自己写）和 **🤖 AI 写变式**（AI 直接产出三个变式，含论点、条件化结论与分歧点，约 20–40 秒）。

## 八、每天/每周怎么用

**每天（3 分钟速览）**：思辨页从上往下 → 看今日议题 + 类型/骨架标签 → 扫正反方论据 → 看「💥 对撞点」与「🧩 条件化结论」（AI 题自带）。

**每周 2–3 次（15 分钟训练）**：按「🎯 今日思辨训练」四段走完 → 打类型小测 → 点「⬜ 标记已练完」（计入统计与去重）→ 写复盘。

**周末（10 分钟）**：做一次三连变式；把本周攒的论据整理进论据库。

命令行：

```powershell
python -m app.thinking_coach --plan       # 今日 15 分钟训练
python -m app.thinking_coach --quiz       # 类型识别小测
python -m app.thinking_coach --variant    # 三连变式引导
python -m app.thinking_coach --evidence   # 论据库
python -m app.thinking_coach --stats      # 训练统计（本周/累计/连续/类型分布）
```

## 十一、综合训练：思辨 × 表达打通（2026-09-14 新增）

把**今日思辨议题直接当作你的即兴说服题**，一次练习同时喂两个模块。

- 位置：「📣 表达能力」页的「🔗 综合训练：思辨 × 表达」卡片（思辨页「🎯 今日思辨训练」右上角也有「🎤 用它练口述」一键跳过来）
- 内容：今日议题 + 题型/骨架/关键变量 + 对撞点 + **2 分钟口述计划**（0–10 秒钩子 → 10–30 秒亮立场 → 两段理由 → 预判反驳 → 条件化收尾 + 行动号召）
- **🎤 AI 写说服脚本**：AI 直接写出可照读的稿子——钩子原话、两条理由（含机制与话术模板）、预判对方最强反驳并化解、条件化收尾与行动号召，外加**现场表达要点**（停顿位置、需要重音的词、语速与眼神提醒）
- **✅ 一键双打卡**：同时记「表达能力·即兴段」与「思辨·今日议题」，两个模块的进度与连续天数一起涨
- 检查清单 6 条（钩子/先结论/论据机制/钢人原则/条件化结论/行动号召）合并了两侧的复盘要点

命令行：

```powershell
python -m app.practice_bridge --plan      # 今日综合训练计划
python -m app.practice_bridge --mark      # 一键双打卡
python -m app.practice_bridge --stats     # 综合训练统计
```

**建议顺序**：先在思辨页花 5 分钟想清立场与两条理由 → 到表达能力页生成说服脚本（或自己写提纲）→ 录 2 分钟视频 → 用 6 条清单自查 → 一键双打卡。
