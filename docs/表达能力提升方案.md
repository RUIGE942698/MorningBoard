# 表达能力提升方案（软件内落地版）

> 目标：**在很多人面前把想法讲清楚，并说服、引领别人**。
> 落地方式：知识库补全 + 每日 20 分钟练习系统 + 实战转化机制，全部做进「📣 表达能力」标签页与每晚邮件。
> 建立于 2026-09-13（对应原来只有 23 条静态课、只能"看"的问题）。

## 一、先诊断：你在第几层

表达能力是四层金字塔，多数人卡在「学了很多理论，但从没练输出」：

| 层级 | 能力 | 过去软件教到哪 | 现在怎么补 |
|---|---|---|---|
| 第 1 层 胆量 | 敢开口、不慌、眼神稳 | 教得少 | 第 1–2 周路线：只要求"录满 2 分钟不中断" |
| 第 2 层 结构 | 有条理、有逻辑、有重点 | ✅ 教得多 | 结构化表达模块 25 条 + 第 3–4 周强制 PREP |
| 第 3 层 感染 | 语气、停顿、故事、情绪 | 只提一嘴 | 声音与肢体 11 条 + 故事力 12 条 + 第 5–8 周加练 |
| 第 4 层 应变 | 即兴、控场、化解质疑 | 几乎不教 | 即兴与控场 10 条 + 临场心态 8 条 + 第 9–12 周说服题 |

标签页顶部有**四层自评勾选**，勾完就知道自己该主攻哪层（存在 `cache/expression_state.json`）。

## 三、每日练习系统（20 分钟，四段）

> 铁律：**每天必须开口出声 + 必须录下来**。默读一百遍不如录一遍。

| 时间 | 练习 | 怎么做 |
|---|---|---|
| 5 分钟 | 朗读 | 用当日指定材料（乔布斯演讲/柴静《看见》/TED 开头/新闻联播导语/论文摘要），标停顿与重音，先夸张慢读一遍再正常读 |
| 5 分钟 | 即兴演讲 | 抽当日题目，**不准备直接讲 2 分钟并录像**；结构按周次升级（第 3 周起 PREP、第 5 周起加真实故事、第 9 周起改说服题） |
| 5 分钟 | 复盘录像 | 只记三件事：口头禅次数 / 眼神是否飘 / 重点句有没有被强调 |
| 5 分钟 | 今日课 + 费曼 | 看今日课 → 合上讲义录 60 秒讲给"完全不懂的人" |

- 每段都有**打卡按钮**，标完显示"今日完成 x/4"与**连续打卡天数**。
- 12 周路线见标签页「🗓 12 周进阶路线」（可展开看全部），每阶段都有目标、当日加练、通过标准。
- 即兴题目池 24 个，朗读材料 5 种，按日期自动轮换，不重复。

## 四、三个实战转化机制（治"学了用不出来"）

1. **费曼输出法**：合上讲义 → 录 60 秒 → 假装教完全不懂的人 → 卡壳处回去补。每天只学 1 点 + 输出 1 分钟。
2. **素材库**：三栏随手记（观点金句 / 我的故事 30 秒版 / 数据案例），标签页可直接添加与查看；门槛线是 20 个故事 + 30 个金句。
3. **真实场景清单**：7 条低风险实战（开会第一个发言、用 PREP 回消息、聚会讲话题并追问反馈、说服反对者…），勾选即记录。

## 五、怎么用（每天 3 分钟操作）

1. 打开「每日播报」→「📣 表达能力」
2. 顶部看「🎯 今日练习」，按四段做完，逐段点打卡
3. 往下读「今日表达课」，注意 **🎯 今天就用出去**（AI 给的当日可验证动作）
4. 收尾用费曼法复述 60 秒
5. 手机上也可：每晚 20:00 的邮件里已带**今日练习 + 打卡状态 + 今日课 + 练习动作**

## 七、每周复盘（2026-09-14 新增）

标签页「📅 本周复盘」卡片 + 手机邮件，自动统计并可填写三问：

| 统计项 | 口径 |
|---|---|
| 本周打卡 | 本周（周一~周日）有打卡的天数 / 已过去的天数；另给"四段全做完"的天数 |
| **最近 7 天** | 滚动 7 天口径（周中复盘也有意义） |
| 连续 / 历史最长 | 当前连续打卡天数、历史最长连续 |
| 四段完成次数 | 朗读 / 即兴 / 复盘 / 课+费曼 各做了多少次 |
| 素材库 | 本周新增条数、累计条数（门槛：20 故事 + 30 金句） |
| 实战场景 | 本周完成条数、累计条数 |
| 四层自评变化 | 每次勾选自评都会留痕，周复盘可看本周变化 |

三问复盘（每周填一次，3 分钟，存 `cache/expression_review.json`）：
1. 本周哪一次表达你最满意？为什么（别人给了什么反馈）？
2. 哪里卡住了？（口头禅/结构乱/紧张/被问倒/没素材…）
3. 下周只改一件事，改什么？（写具体动作）—— 这句会显示在卡片上，提醒你下周盯着改

- 手机邮件：**每天**的邮件里都带一行本周统计；**周日**的邮件额外附完整复盘全文。
- 命令行：`python -m app.expression_coach --review`

## 八、怎么更新这套知识库（三种方式）

「📚 静态题库」= 存在你电脑本地的 `knowledge/expression.json`（不联网、不花钱）；「✨ AI 今日生成」= 每天现写的课，不落库。

**方式一：让 AI 批量扩库（推荐，质量稳定）**

```powershell
cd C:\Users\lenovo\Desktop\压缩包\MorningBoard
python tools\expand_expression_kb.py --list                 # 看各模块现有条数
python tools\expand_expression_kb.py --module voice --topics "演讲时的呼吸节奏,如何用音量强调重点"
python tools\expand_expression_kb.py --module persuasion    # 按内置清单继续补该模块
```

脚本会自动：AI 生成 → 校验字段与长度 → 与现有条目去重 → 写入前备份 `expression.json.bak_expand`。
需要环境变量 `DEEPSEEK_API_KEY`（你机器上已配置）。

**方式二：手工加一条**（适合你自己总结的技巧）

编辑 `knowledge/expression.json`，在数组里加一条：

```json
{"t": "技巧名：副标题", "s": "一句话说明解决什么问题",
 "module": "voice", "b": ["方法/步骤", "为什么有效", "带原话的示例", "今天怎么练"],
 "links": ["延伸名词1", "延伸名词2"]}
```

注意：字符串内部只能用中文引号“ ”，不能出现半角双引号（否则 JSON 解析失败）；`module` 取 structure / persuasion / story / voice / improv / mindset。

**方式三：收藏 AI 每日课**
点「✨ AI 换新」生成的课只在当天用；想长期留着，把它的标题和正文按方式二的格式补进 JSON 即可。

**生效方式**：改完保存 → 重启界面（或点「🎲 换一课」）立即生效，不需要重新生成缓存。
**同类机制**：每日一课/思辨/术语库也有各自的扩充入口（`knowledge/knowledge_extra.json`、术语页的「🧠 AI 扩充 / ➕ 新增领域」）。

## 九、综合训练：思辨 × 表达打通（2026-09-14 新增）

「🔗 综合训练：思辨 × 表达」卡片把**今日思辨议题当成你的即兴说服题**，一次练完两个模块：

- **议题与弹药**：今日议题 + 题型（四类延伸题）/ 骨架 / 关键变量 / 对撞点（来自思辨模块）
- **2 分钟口述计划**：0–10 秒钩子 → 10–30 秒亮立场 → 30–85 秒两条理由 → 85–105 秒预判反驳（钢人原则）→ 105–120 秒条件化收尾 + 行动号召
- **🎤 AI 写说服脚本**：一键生成可照读稿——钩子原话、含机制与话术模板的两条理由、预判并化解对方最强反驳、条件化收尾，外加**停顿/重音/语速/眼神**的现场要点
- **✅ 一键双打卡**：同时记表达能力的「即兴」段与思辨的今日议题
- **6 条自查清单**：钩子开场 / 先结论 / 论据有机制 / 预判最强反驳 / 条件化结论 / 给出具体行动号召

命令行：`python -m app.practice_bridge --plan | --mark | --stats`
思辨页「🎯 今日思辨训练」右上角也有「🎤 用它练口述」直接跳到这张卡片。
