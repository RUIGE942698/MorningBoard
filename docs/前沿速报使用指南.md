# 前沿速报 · 使用指南

> 每日 25 条高质量前沿情报（AI 10 / 科技 4 / 物理 3 / 医学 3 / 生物 3 / 数学 2），
> 六维百分制筛选，配"读懂它"降门槛、**每日生词本（按天存档）**与**次日生词复习推送**。

## 一、在哪儿看

| 入口 | 位置 | 内容 |
|---|---|---|
| **播报界面** | 桌面「每日播报」→「📰 新闻联播」→ 滚到底部「⚡ 前沿速报」 | 25 条，六分组，含分数/难度/摘要 |
| **桌面弹窗** | 自动，后台每 60 分钟检查 | 只有 ≥70 分的新条目才弹（最多 3 条，点击开原文） |
| **生词复习弹窗** | 自动，**晚间 19:00–23:00 内每天一次**（也可手动 `--review`） | 当天新增的生词，最多 8 条，点词条可搜索 |
| **邮件** | 每晚 20:00 | 25 条 + 人话版 + 先修知识 + 今日生词本 |

## 二、界面上的操作

1. **难度：全部 ▾** —— 全部 / 通俗+中等 / 仅通俗 / 仅专业（🟢🟡🔴 徽标直接标在每条上）
2. **📓 生词本 N ▾**
   - 「查看今日生词」→ 生词本弹窗（见第四节）
   - 「导出 Markdown 到桌面」
3. **信源入口 ▾** —— **33 个信源官网首页**（量子位、机器之心、InfoQ、掘金、Nature、Science、Cell、The Lancet、NEJM、JAMA、PNAS、eLife、IEEE Spectrum、Ars Technica、arXiv…）
4. **每条三种点击**：点标题＝原文菜单；点「详情/延伸」＝读懂它弹窗；词条下划线可点＝跳术语词典

## 三、「详情/延伸」= 读懂它

```
【人话版】        一句话说清（不用术语）
【先修知识】      仅"专业"级：读这条前建议先知道的概念
【关键概念】      生僻名词逐个解释（词条可点 → 术语词典）
【为什么值得关注】一句话价值判断
【原始摘要】      摘要 + 英文原标题 + 同主题其它来源
[打开原文][百度][知乎][百度学术][arXiv检索][必应]
```
难度：🟢通俗（直接读）｜🟡中等（看人话版即可）｜🔴专业（先看先修知识）。

## 四、每日生词本（三种视图 + 三种导出）

打开：前沿速报 → 「📓 生词本 ▾」→ 查看今日生词

- **分组：日期** —— 顶部日期条（近 14 天，括号是当天词数），点日期看当天；词条带 `新增` / `×N`（当天出现次数）/ `出自：某条新闻`
- **分组：领域** —— 按 前沿AI / 科技 / 物理 / 医学 / 生物 / 数学 汇总全部已收集概念（每领域最多显示 60 条）
- **导出今日** → `桌面\每日播报生词本\生词本_2026-09-12.md`
- **导出本月汇总** → `生词本_2026-09_月度汇总.md`（含领域分布、高频概念 TOP20、每日明细）
- **导出全部历史** → `生词本_全部历史_2026-09-12.md`（按天分节）

### 存档位置
| 文件 | 内容 | 限制 |
|---|---|---|
| `cache\vocab\<日期>.json` | **按天独立存档**（当天全部词条 + 新增标记 + 出现次数 + 出处） | 无上限，永久保留 |
| `cache\frontier_vocab.json` | 滚动总表（跨天累积去重，含 first_seen/last_seen/hits） | **上限 5000 条** |
| `cache\frontier_review_state.json` | 复习推送状态（每天只弹一次） | — |

## 五、睡前复习推送（生词）

| 项 | 说明 |
|---|---|
| **时机** | **晚间 19:00–23:00 之间**，每天只推一次（速报进程每 60 分钟检查，落在窗口内的第一次检查触发） |
| **内容** | **当天新增的生词**，最多 8 条（当天没有新增时，回退到最近一个有存档的日期） |
| **形态** | 右下角置顶小窗「📓 睡前复习 · 日期 新增 N 个」；**点词条可搜索**；30 秒自动消失，或点「知道了」 |
| **状态** | `cache/frontier_review_state.json`（记录当天已复习，避免重复打扰） |
| **错过窗口** | 当天不再补弹（次日窗口内再推当天的）——所以电脑要在 19:00–23:00 之间开机 |
| **手动触发** | `python frontier_watch.py --review`（忽略时段与每日限制） |
| **换回"前一天"语义** | 把 `frontier_watch.py` 里 `REVIEW_SAME_DAY = True` 改成 `False` |
| **调整时段** | 改 `frontier_watch.py` 里 `REVIEW_WINDOW = (19, 23)`（24 小时制，左闭右开） |

## 六、命令行

```powershell
cd C:\Users\lenovo\Desktop\压缩包\MorningBoard
python -m app.frontier --refresh --dump      # 抓取并打印六维明细

python frontier_watch.py --review            # 立即弹一次生词复习
python frontier_watch.py --monthly           # 导出本月生词汇总
```

## 七、调参（`app/frontier.py` 顶部）

| 常量 | 作用 | 当前 |
|---|---|---|
| `QUOTA` | 各领域条数 | ai 10 / tech 4 / physics 3 / medicine 3 / biology 3 / math 2 |
| `MIN_SCORE` / `PUSH_MIN_SCORE` | 入选线 / 弹窗线 | 50 / 70 |
| `TAU_DAYS` | 各省时效衰减 τ | AI 1.5 天、科技 2.5、生物医学 3、数理 5 |
| `DOMAIN_BOOST` | 领域偏好加权 | AI +5、科技 +2 |
| `PER_SOURCE_MAX` / `SOURCE_MAX` | 单源上限 | 3（预印本 2） |
| `VOCAB_CAP` | 生词滚动总表上限 | 5000 |
| `EXPLAIN_VERSION` | 改了"读懂它"提示词就 +1 | 2 |

改完规则**需重启速报进程**：`Get-Process pythonw | Stop-Process -Force`，再双击
